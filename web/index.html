Integration Guide & API Documentation

Complete setup guide, multi-turn session persistence, and code examples for GeminiGo

1. Interactive IDE & Client Setup

GeminiGo is fully OpenAI-API compatible. Use it seamlessly with your favorite tools:

Cursor IDE

  1. Open Cursor Settings (Ctrl + , / Cmd + ,).
  2. Navigate to Models → OpenAI API.
  3. Set Override OpenAI Base URL to: http://localhost:8081/v1
  4. Enter any API key configured in the API Keys tab.
  5. Add model IDs: gemini-3.7-flash hoặc gemini-3.7-pro.

Cline / Roo Code / Continue (VS Code)

  • Provider: Select OpenAI Compatible
  • Base URL: http://localhost:8081/v1
  • Model ID: gemini-3.7-flash hoặc gemini-3.7-pro

2. Session Context Retention (X-Session-ID)

Pass a custom X-Session-ID header to maintain persistent browser sessions for image and video generation. The same Google Gemini conversation context is reused across requests with the same session ID:

# X-Session-ID works for image/video generation (NOT chat):
curl -X POST http://localhost:8081/v1/videos/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "X-Session-ID: sess_video_001" \
  -d '{
    "model": "gemini-veo",
    "prompt": "A cute kitten playing with a ball of blue yarn"
  }'

Note: Chat completions (/v1/chat/completions) are stateless — send full message history with each request. X-Session-ID only affects media generation pipelines. If your server has no API keys configured, omit the Authorization header.

3. Image Generation API (Imagen 3)

Generate high-quality images via Playwright CDP browser pipeline. Images are captured as Base64 JPEG data URL or hosted file URLs:

# Request Image Generation (Base64 JPEG) — replace YOUR_API_KEY with a key from the API Keys tab
curl -X POST http://localhost:8081/v1/images/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "prompt": "A futuristic glowing cybernetic panther in a neon city",
    "model": "gemini-imagen",
    "response_format": "b64_json"
  }'

# Python Example — set your API key
import requests, json, base64

response = requests.post("http://localhost:8081/v1/images/generations",
    headers={"Authorization": "Bearer YOUR_API_KEY"},
    json={
        "prompt": "A serene lotus pond at sunset, watercolor digital art",
        "model": "gemini-imagen",
        "response_format": "b64_json"
    }
)
b64_data = response.json()['data'][0]['b64_json']
with open("output.jpg", "wb") as f:
    f.write(base64.b64decode(b64_data))
print("Saved output.jpg successfully!")

4. Video Generation API (Gemini Veo)

Generate MP4 videos powered by Google Veo with persistent session retention. Videos are downloaded via Chrome browser events and hosted locally under /v1/files/:

# Request Video Generation — replace YOUR_API_KEY with a key from the API Keys tab
curl -X POST http://localhost:8081/v1/videos/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "X-Session-ID: sess_video_001" \
  -d '{
    "prompt": "A cute kitten playing with a ball of blue yarn",
    "model": "gemini-veo"
  }'

# Response Example:
# {
#   "created": 1785258686,
#   "data": [{
#     "revised_prompt": "Generate a video of A cute kitten playing with a ball of blue yarn",
#     "url": "http://localhost:8081/v1/files/video_1785258686_ZCCCCB.mp4"
#   }]
# }
